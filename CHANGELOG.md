# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0.html),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-27

### Added
- Single PDF to Word conversion
- Batch conversion of multiple PDFs
- PDF information viewer (pages, size)
- Preserves text formatting and layout
- Cross-platform support (Windows, macOS, Linux)
- Progress feedback during conversion

### Features
- Uses pdf2docx library for high-quality conversion
- Supports password-protected PDFs
- Maintains document structure (headings, paragraphs, tables)
- Simple command-line interface
- No GUI dependency - pure CLI tool
